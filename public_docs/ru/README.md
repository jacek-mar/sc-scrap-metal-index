# SC Scrap Metal Index — v0.3

[English](../README.md)

Неофициальный справочник предметов Star Conflict для операторов серверов
сообщества и авторов модификаций. Hub 1.99.0.167293, **штатные файлы**.
Пакеты конфигурации могут изменять ваши файлы; эти изменения здесь не отражены.

Откройте [страницу поиска](../site/index.html#lang=ru) или дважды щёлкните
`site/index.html`, скачав всю папку. Интернет и сервер не нужны.
Сохраняйте структуру папок. Для локального размещения выполните
`python -m http.server 8000 --directory dist` из папки, содержащей `dist`,
и откройте `http://localhost:8000/site/`. Для статического размещения скопируйте
всю папку и используйте `site/index.html` как точку входа. Компиляция и установка
не требуются. См. [руководство по поиску](../docs/ru/using-the-search.md).

Например, найдите **Nebula GS**, выберите строку корабля с нужным отображаемым
названием, откройте сведения и скопируйте `Ship_Race1_S_T4_Glass`.
Его `defined_in` — `star conflict\data\gamedata\def\ex\ship.lua:26711`:
откройте файл в библиотеке Steam и перейдите к строке 26711. В сведениях
перечислены и остальные места, где встречается корабль: сгенерированные
серверные копии, которые не следует изменять, предметы и таблицы со ссылками
на него, а также место хранения корабля в базе данных
(`cosmosim_<WinUser>.accounts.vessels[].defName`). Эти пути помогают изучать
собственные файлы и резервную копию базы данных; они не доказывают, что
выдача предмета сработает.

Для идентификации используйте **kind + defName**. Один `storeItemId` может
относиться ко многим предметам; никогда не выбирайте первое совпадение.
Названия `category` общие для категории, а `derived` составлены нами.
Неустановленная область учётной записи остаётся неустановленной.
Пути в базе данных перечислены по типам (`data/db_by_kind.csv`): где может
храниться предмет этого типа и какое значение туда записывается.
Это не разрешение на выдачу предмета. История боёв и статистики пока не охвачена.

Загрузки: [CSV учётных записей](../data/items.csv),
[JSON учётных записей](../data/items.json), [CSV всех определений](../data/items_all.csv),
[JSON всех определений](../data/items_all.json), [поля базы данных](../data/db_fields.csv),
[схема](../data/schema.json), [количества и хеши](../data/manifest.json).
[Словарь данных](../docs/ru/data-dictionary.md) объясняет все 24 столбца.
Ячейки списков в CSV содержат JSON; пустое значение означает отсутствие данных,
а не ноль. Как пересобрать всё из собственной установки игры и как разместить
сайт, описано в [руководстве по сборке и размещению](../docs/rebuild-and-host.md)
(на английском).
